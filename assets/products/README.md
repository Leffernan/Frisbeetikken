# Produktbilder

Legg front- og baksidebildet til hver disc i denne mappen. Bruk dobbel understrek mellom feltene:

```text
001__Innova-Destroyer__front__10.jpg
001__Innova-Destroyer__back__10.jpg
```

Varenummeret og graden må stemme med `data/products.json`. Kjør `npm run sync:images` før publisering. GitHub Pages-jobben gjør også dette automatisk.
